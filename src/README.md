# Source Code

This directory contains the source code for the Drug Safety Signal Detector & Regulatory Submission Readiness Checker.

## Layout

- `backend/`: FastAPI application handling user intents, FAERS database connections, PRR calculations, CTD dossier parsing, and watsonx.ai interactions.
- `frontend/`: React 18 dashboard for the user interface, visualizing safety signals and dossier gap reports.

See the root `README.md` and `docs/setup-guide.md` for instructions on how to run this code.
